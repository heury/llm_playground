## 어시스턴트

가장 추천하는 건 **“가상의 상품 정보를 Full SFT로 학습시키고, 처음 보는 질문 표현에도 답하는지 확인하기”**입니다. 실제 상식 대신 직접 만든 정보를 쓰면, 기존에 알고 있던 지식과 이번에 학습한 지식을 구분하기 쉽습니다.

예를 들어 가상의 회사 ‘루멘랩’에 다음 상품이 있다고 정합니다.

| 상품 | 색상 | 배터리 사용 시간 | 보증 기간 |
|---|---|---|---|
| 네보 | 청록색 | 13시간 | 2년 |
| 타린 | 주황색 | 7시간 | 4년 |
| 모벡 | 보라색 | 19시간 | 1년 |

실제 실험에서는 **상품 20개 × 속성 3개 = 사실 60개** 정도로 시작하면 충분합니다. 이름과 속성은 규칙 없이 배정하세요. 이름만 보고 정답을 추측하기 어려워야 합니다.

**1. 같은 사실을 여러 표현으로 학습합니다.**

사실 하나당 질문 5개를 만들어 총 300개 정도의 학습 샘플을 구성합니다.

```text
Q: 네보의 배터리 사용 시간은?
A: 네보의 배터리 사용 시간은 13시간입니다.

Q: 네보는 충전 후 얼마나 사용할 수 있어?
A: 네보는 충전 후 13시간 사용할 수 있습니다.
```

현재 [SFTDataset](../../projects/minimind/dataset/lm_dataset.py)에 맞는 JSONL 형식은 다음과 같습니다. 각 줄에 샘플 하나를 넣습니다.

```json
{"conversations":[{"role":"user","content":"네보의 배터리 사용 시간은?"},{"role":"assistant","content":"네보의 배터리 사용 시간은 13시간입니다."}]}
```

**2. 평가 질문은 학습 전에 따로 만듭니다.**

| 평가 종류 | 예시 | 확인하는 것 |
|---|---|---|
| 학습 문장 그대로 | 네보의 배터리 사용 시간은? | 학습 샘플 암기 |
| 새로운 표현 | 네보를 완충하면 몇 시간 쓸 수 있나요? | 표현이 바뀌어도 지식 회상 |
| 속성 구분 | 네보의 보증 기간은? | 상품과 속성을 정확히 연결 |
| 미등록 상품 | 제룬의 배터리 사용 시간은? | 학습한 정보를 엉뚱한 대상에도 답하는지 |

새로운 표현은 **사실마다 2개씩, 총 120문항**을 준비하면 됩니다. 이 실험의 핵심은 *같은 사실을 묻되 질문 문장은 학습에서 제외하는 것*입니다. 사실 자체를 학습에서 빼면 다른 실험이 됩니다.

**3. 동일한 모델의 학습 전후를 비교합니다.**

- 시작 모델은 대화가 가능한 기존 SFT 체크포인트를 사용합니다. 새 지식 학습을 대화 형식 학습과 분리하기 쉽습니다.
- 첫 시도는 `batch_size=8`, `accumulation_steps=1`, `learning_rate=1e-5`, `epochs=10` 정도를 출발점으로 잡습니다.
- 짧은 문답이므로 `max_seq_len=256`부터 시작하되, 채팅 템플릿을 포함한 답변이 잘리지 않는지 확인합니다.
- 각 에포크의 가중치로 같은 평가를 수행하고, 추론은 가능하면 `do_sample=False`로 고정합니다.

이는 **실험용 초기 설정**이며, 성공이 보장되는 값은 아닙니다. 모델 구조 설정은 시작 체크포인트와 맞춰야 합니다.

**4. loss보다 정답률로 판단합니다.**

예를 들어 다음 기준을 미리 정할 수 있습니다.

- 학습 문장 정답률 **95% 이상**
- 새로운 표현 정답률 **80% 이상**, 학습 전보다 뚜렷하게 상승
- 별도로 준비한 일반 대화 20문항에서 반복 출력이나 응답 붕괴가 없는지 확인

“13시간”처럼 정답 값이 정확한지 채점하고, 다른 수치를 함께 말하면 오답 처리하세요. **학습 문장만 맞히면 문장 암기 증거이고, 새로운 표현에서도 맞히면 해당 사실을 회상하는 능력이 생겼다는 증거**입니다. 미등록 상품에 대한 거절은 별도로 학습하지 않았다면 필수 통과 조건으로 삼지 않는 게 좋습니다.

현재 [Full SFT 코드](../../projects/minimind/trainer/train_full_sft.py)는 검증 루프가 없고 같은 이름의 가중치를 덮어쓰므로, 에포크별 비교를 하려면 저장 방식을 조금 보완해야 합니다. 아직 학습은 실행하지 않았습니다.

## 어시스턴트 — 진행 설명, 이후 사용자에 의해 중단

지정한 모델의 설정과 로컬 실행 환경을 확인한 뒤, 가상 상품 지식을 Full SFT로 학습시켜 학습 전후 정답률을 비교하겠습니다.

이 모델은 영어로 학습된 64M 모델이라, 언어 능력의 영향을 줄이도록 상품명과 질문을 영어로 구성하겠습니다. 로컬 GPU 드라이버가 작동하지 않아 CPU로 실행하며, 상품 20개의 사실 60개를 학습하고 별도로 만든 질문 120개로 평가하겠습니다.

> 위 GPU 판단은 아래 후속 확인에서 샌드박스 접근 제한 문제로 정정되었습니다. CPU 학습은 실행하지 않았고 실제 학습은 GPU에서 수행했습니다.

## 어시스턴트 — 진행 설명

GPU 장치는 있지만 현재 Python 환경에서 인식하지 못하는 것으로 보입니다. 장치와 드라이버 연결 상태를 확인하고 GPU 실행을 다시 시도하겠습니다.

RTX 3080 Ti 12GB가 확인됐습니다. 샌드박스 안에서 GPU 접근이 제한된 것이었고, 샌드박스 밖에서는 CUDA가 정상 작동합니다. GPU로 학습을 진행하고, 원본 모델은 보존한 채 별도 체크포인트와 평가 결과를 저장하겠습니다.

학습이 끝났습니다. 새로운 표현의 질문 120개에서 정답률이 학습 전 0.8%에서 학습 후 100%로 올랐습니다. 다만 일반 질문에도 “35 hours”나 “silver”처럼 상품 속성으로 답하는 퇴행이 나타났고, 미등록 상품의 정보도 지어냈습니다. 이 결과와 한계를 보고서에 함께 기록하겠습니다.

## 어시스턴트 — 최종 결과

RTX 3080 Ti에서 `caspar/MiniMind-Dense-64M-Mixed-SFT-v1.0`으로 테스트했습니다. **새 지식은 학습했지만, 일반 대화 능력이 크게 퇴행했습니다.**

가상 상품 20개의 사실 60개를 영어 문답 300개로 Full SFT했습니다. 설정은 10 epochs, LR `1e-5`, batch 8입니다.

| 평가 | 학습 전 | 학습 후 |
|---|---:|---:|
| 학습 문장 300개 | 0.33% | **100%** |
| 표현을 바꾼 질문 120개 | 0.83% | **100%** |

학습 후에는 `Nevo를 완충하면 얼마나 사용할 수 있나?`라는 새로운 표현에도 정확히 `35 hours`라고 답했습니다.

다만 **“2 + 3?”에도 `35 hours`, “hot의 반대말?”에도 `silver`**라고 답했습니다. 미등록 상품의 배터리 시간도 지어냈습니다. 좁은 상품 데이터만 학습해 과적합된 결과입니다.
