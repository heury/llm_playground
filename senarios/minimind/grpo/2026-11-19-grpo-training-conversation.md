## 어시스턴트

노트북을 참고해 [GRPO 산수 문장제 시나리오](../../../test_scenarios/minimind/grpo-word-problems-tour.md)를 작성했습니다. **모델이 익숙한 `풀이 + #### 정답` 형식으로 학습하는 구성**입니다.

문제 예시는 다음과 같습니다.

```text
Tom has 3 apples. Tom gets 4 more apples.
How many apples does Tom have now?

Solve step by step.
End your answer with #### followed by the final number.
```

```text
Tom has 3 + 4 = 7 apples.
#### 7
```

| 항목 | 시나리오 |
|---|---|
| 시작 모델 | 원본 MiniMind Dense 64M SFT |
| 문제 | 2~9의 덧셈·곱셈 문장제 |
| 데이터 | 학습 128개 / 평가 256개 |
| 보상 | 마지막 `#### 숫자`가 정답이면 1 |
| 생성 길이 | 최대 96토큰 |
| 학습 | 2 epochs, batch 4, 질문당 6개 생성 |
| LR / KL 계수 | `3e-7` / `0.1` |
| 손실 | `grpo` 명시 — 노트북 기본값은 CISPO |

**먼저 학습 문제 16개에서 96개 답변을 생성해 점검합니다.** 최소 4개 질문에서 정답과 오답이 함께 나올 때 본 학습에 들어갑니다. 보상이 모두 같으면 중단하고 원인을 보고하도록 했습니다.

평가에서는 정답률·형식 오류·생성 길이·일반 응답 퇴행을 비교합니다. 이름과 물건만 달라지고 같은 계산식이 겹칠 수 있어, 결과를 새로운 계산식에 대한 일반화로 해석하지 않도록 명시했습니다.

새 학습은 아직 실행하지 않았습니다.

## 어시스턴트

GRPO 학습과 평가를 완료했습니다. **평가 256문제 정답률이 12.5%에서 37.9%로 상승했습니다.**

원본 SFT 모델에서 추가 SFT 없이, 문장제 128개로 **2 epochs·64단계**를 학습했습니다.

| Greedy 평가 | 학습 전 | 학습 후 |
|---|---:|---:|
| 전체 정답 | 32/256 (12.5%) | **97/256 (37.9%)** |
| 덧셈 | 3.9% | **13.3%** |
| 곱셈 | 21.1% | **62.5%** |
| 형식 오류 | 6개 | **1개** |

정답으로 바뀐 문제는 73개, 오답으로 바뀐 문제는 8개였습니다. 일반 질문 8개에서 전반적인 응답 붕괴는 관찰되지 않았지만, 기존 오답과 반복은 남았습니다.

평가 문제의 **계산식 216/256개는 학습에도 등장**하므로, 이번 결과는 해당 문장제 분포에서의 개선으로 해석해야 합니다. 저장한 FP32 모델의 정확한 재로딩도 검증했습니다.
