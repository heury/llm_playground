# 노트북 평가·업데이트 시나리오

대상은 `skills/notebook-review/` Skill과 `agents/notebook-review/`의 호환 연결점입니다. 지표 버전은 2.0입니다. 아래는 재사용할 절차·판정 기준이며
실행 결과가 아닙니다. 실제 실행은 `outputs/notebook-review/<실행 ID>/`,
보고서는 `reports/notebook-review/<실행 ID>.md`에 기록합니다.
모델/클라이언트 버전, 지표·계약 버전, 입력 소스 해시, 실행 범위도 기록합니다.

| 시나리오 | 입력·절차 | 기대 판정 |
| --- | --- | --- |
| 미확인으로 인한 고득점 | 역할의 20개 항목 중 통과 16·미확인 4, 미충족/주요 결함 없음 | 관측 100점·확인률 80%·범위 80~100점이지만 판단 보류 |
| 핵심 미확인 | 통과 19·핵심 항목 미확인 1 | 하한 95점이어도 판단 보류 |
| 고득점의 주요 결함 | 통과 19·미충족 1, 해당 발견이 주요 결함 | 95점이어도 수정 후 사용 |
| 일부 절 설명 누락 | S2.1을 두 절에 적용하고 한 절은 통과, 다른 절은 shape 설명 누락 | 항목 전체 미충족. 두 절 근거와 누락 위치 기록 |
| 참조 구현 차이 | GPT 노트북과 실제 참조 previous_chapters.py를 계약으로 지정 | projects/ 사본을 억지로 기준 삼지 않고 실제 구현과 비교 |
| 편집 전후 의미 훼손 | 원문/수정본 diff에서 필수 조건·정의 하나 삭제 | 현재 E5 재평가와 별개 보존 검증 모두에서 훼손·복구 필요 기록 |
| 평가 범위 변경 | 수정 후 필수 이론이나 적용 제외를 바꾸는 제안 | 현재 점수와 분리, 새 계약 버전·기준선 없이는 전후 증감 비교 금지 |
| 필요한 검증 미실행 | 설명·셀 수정 후 환경 부족으로 필수 marimo 검사 미실행 | 수정 파일과 미실행 영향 제공, 업데이트 완료를 주장하지 않음 |

실제 평가자 검증은 위 입력을 별도 사본과 완성한 공통 계약으로 제공하고 보고서가 기대 조건을
만족하는지 확인합니다. 원본 노트북이나 기준선을 검증 목적으로 덮어쓰지 않습니다.

자동화된 검증은 저장소 루트에서 `python3 -m unittest discover -s skills/notebook-review/tests -v`로
실행합니다. 계약·점수 스크립트의 동작을 확인하며 실제 평가 Agent의 판단 품질을 검증하지는 않습니다.
