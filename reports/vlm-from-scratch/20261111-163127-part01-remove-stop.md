# 1부 실행 대기 제거

`notebooks/vlm-from-scratch/notebooks/part-01-minimal-vlm.py`에서 실행 버튼과 `mo.stop()`을 제거했다. 실행 안내와 README도 1부의 자동 시작 동작에 맞췄다. 모델 변경 순서를 보장하는 실행 의존성은 유지했다.

저장소 루트에서 Python AST 구문 검사 및 프로젝트 가상 환경의 `marimo check --strict notebooks/part-01-minimal-vlm.py` 검사를 수행해 통과했다. marimo 명령의 작업 디렉토리는 `notebooks/vlm-from-scratch/`이며 대상은 절대 경로로 지정했다. 결과는 `outputs/vlm-from-scratch/20261111-163127-part01-remove-stop/marimo-check.log`에 저장했다. 단순 실행 제어 변경이므로 새 단위 테스트는 추가하지 않았다. 모델 다운로드·실제 학습·추론은 실행하지 않았다. 모델·데이터 리비전은 해당하지 않는다.
