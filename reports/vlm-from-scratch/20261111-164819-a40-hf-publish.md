## 지표와 검증 한계

- 1부: Flickr8k 2,000개·6에포크. 학습 전후 시연은 독립 캡션 벤치마크가 아니다.
- 2부: 노트북 테스트 200개, IoU 임계값 0.5. TP/FP/FN 154/113/197, 정밀도 0.577, 재현율 0.439, F1 0.498, 매칭 상자 평균 IoU 0.695.
- 3부: 학습 3,600개·보류 400개 중 50개를 평가해 완전/포함 일치 모두 17/50(34%). 공식 VQA consensus 점수와 다르다.
- 6부: 작업 분류기의 32개 학습 예시에서 마지막 훈련 정확도 100%. 독립 분류 성능이 아니다. 실제 저장 분류기의 CPU 복원·유한 출력과 세 시연 질문의 클래스 0/1/2를 확인했다.
- 7부: A-OKVQA 2,000개를 실제로 읽었으며 fallback이 없었다. 동일 학습 샘플 모음의 100개에서 CoT 84/100, 직접 답변 76/100, 추론 텍스트 생성 비율 65%였다. 보류 세트 일반화나 사고 과정의 충실성 평가가 아니다.
- 8부: `common-canvas/commoncatalog-cc-by`의 `refcoco` 구성이 없어 `detection-datasets/coco` 2,000개와 합성 지칭 표현으로 전환했다. 마스크가 없을 때는 경계 상자 모서리를 다각형으로 사용한다. 실제 RefCOCO 학습·공식 지칭 분할 벤치마크 결과로 해석하지 않는다. 공개 `training_data.json`에 fallback을 명시했다.
- 10부: 학습·증류 호출과 실제 구조적 가지치기를 실행하지 않는 압축 시연이다. baseline과 student는 같은 ViT-Base/SmolLM-135M 백본과 무작위 프로젝터·LM head를 사용한다. FP32 952.6MiB, INT8 322.1MiB, 2.96배는 packed 가중치를 포함한 직렬화 크기 비율이며 GPU 메모리·속도 배율이 아니다. 공개 `demo_status.json`에 명시했다.
- 11부: 사전 학습된 생성 파이프라인을 실행해 그림을 저장했고 새 가중치를 학습하지 않았다.
- 12부: 고정된 LaTeX 수식 15개를 20회 반복한 300개 항목으로 3에포크 학습했다. IAM은 별도 사전 학습 TrOCR 시연 입력이다. IM2LATEX 또는 일반 OCR 벤치마크는 수행하지 않았다.
- 4·5·9부 등 나머지 시연에도 외부 독립 품질 인증을 부여하지 않는다. 모델 입력·학습 목표는 원문의 영어/LaTeX이며 한국어는 실습 설명이다. 한국어 모델 능력을 평가하지 않았다.

## 실행 방법과 환경

원격 작업 디렉토리는 `/workspace/vlm-publish/notebooks/vlm-from-scratch`, 출력은 같은 작업 루트의 `outputs/vlm-from-scratch/20261111-164819-a40-hf-publish/`였다. 네트워크 볼륨 `/workspace`에 코드·캐시·체크포인트를 저장했다.

```bash
# 원격 프로젝트 디렉토리
UV_CACHE_DIR=/workspace/cache/uv uv sync --locked
apt-get update -qq
apt-get install -y -qq fonts-noto-cjk
.venv/bin/marimo check --strict notebooks/part-*.py

# detached setup.sh가 HF_TOKEN_PATH/HF_HOME/UV_CACHE_DIR를 설정한 상태에서 실행
.venv/bin/python -u /workspace/vlm-publish/run_publish.py
```

## 공개 검증과 리소스 삭제

- Pod: `db01swjyny9e6b`, A40 1개, CA-MTL-1 Secure Cloud. 생성 전 카탈로그에서 재고 Low·GPU $0.59/시간을 확인했다.
- 공식 템플릿 조회로 선택: `runpod-torch-v280`, 이미지 `runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404`. 프로젝트 torch 2.12 환경은 별도 uv 가상 환경이며 CUDA 하한 13.0으로 생성했다. SSH `22/tcp`만 노출했다.
- 임시 네트워크 볼륨: `dajs14ligm`, 200GB. 표준 저장 요금 $0.07/GB/월은 [Runpod 요금표](https://www.runpod.io/pricing) 기준 사용 시간에 비례한다. 총 실청구액을 감사한 결과는 아니다.
- `pod-delete.json`: `deleted=true`. 삭제 후 새 조회 `pod-after-delete.json`: `code=not_found`, HTTP 404.
- `volume-delete.json`: `deleted=true`. 새 목록 `volumes-after-delete.json`은 `[]`이다. 이번 작업에서 만든 Pod·볼륨은 남아 있지 않다.

```bash

```

`.env`를 원격 또는 Hub로 전송하지 않았다. HF 인증 값은 암호화된 SSH 표준 입력으로 임시 비공개 파일에 전달했고, 해당 파일은 볼륨 삭제로 제거됐다. 공개 저장소에는 모델·토크나이저·처리기·소스·환경·지표·파일 해시를 보관하고 데이터 이미지·인증 값·옵티마이저 체크포인트는 업로드하지 않았다.
