# PyTorch 지원 범위 확장

`notebooks/vlm-from-scratch/`의 uv 프로젝트에 `torch>=2.6,<3`을 적용했다. 해당 torch 선언은 사용자가 이미 편집한 상태여서 유지하고, torch 2.8을 요구하던 `torchvision>=0.23,<0.24`를 `torchvision>=0.21,<1`로 넓혔다. `requirements.txt`도 동일하게 맞추고 `uv.lock`을 갱신했다.

저장소 루트에서 `UV_CACHE_DIR=/tmp/vlm-uv-cache uv lock --project notebooks/vlm-from-scratch` 및 `uv lock --check --project notebooks/vlm-from-scratch`를 실행해 성공했다. 기존 잠금 버전 torch 2.8.0, torchvision 0.23.0은 유지된다.

임시 디렉토리에 프로젝트 선언과 잠금을 복사한 뒤 `uv lock --project <임시 경로> --upgrade-package torch==2.6.0 --upgrade-package torchvision==0.21.0`을 실행했다. torch 2.6.0 / torchvision 0.21.0의 의존성 해결도 성공했다. 환경은 Linux, uv가 선택한 CPython 3.12.15이며 결과는 `outputs/vlm-from-scratch/20261111-111516-torch-range/`에 보관했다.

패키지 설치, GPU 학습·추론 및 지원 범위 내 모든 버전의 런타임 검증은 수행하지 않았다. 모델·데이터 리비전은 해당하지 않는다.
