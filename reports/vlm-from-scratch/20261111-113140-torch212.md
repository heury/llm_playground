# PyTorch 2.12 적용

사용자 요청에 따라 `notebooks/vlm-from-scratch/pyproject.toml` 및 `requirements.txt`의 PyTorch 범위를 `>=2.12,<2.13`으로 변경했다. `uv.lock`에서 torch 2.12.1, torchvision 0.27.1, triton 3.7.1으로 해결되었다. CUDA 관련 전이 의존성도 잠금 파일에서 함께 갱신되었다.

작업 디렉토리: 저장소 루트. Linux / CPython 3.12.15 / uv 0.13.5에서 다음 명령이 성공했다.

```bash
UV_CACHE_DIR=/tmp/vlm-uv-cache uv lock --project notebooks/vlm-from-scratch --upgrade-package torch --upgrade-package torchvision
UV_CACHE_DIR=/tmp/vlm-uv-cache uv lock --check --project notebooks/vlm-from-scratch
```

산출물: `outputs/vlm-from-scratch/20261111-113140-torch212/`. 잠금 파일의 torch 버전이 2.12 계열인지 확인했다. 실제 패키지 설치 및 GPU 학습·추론은 실행하지 않았다. 모델·데이터 리비전은 해당하지 않는다.
