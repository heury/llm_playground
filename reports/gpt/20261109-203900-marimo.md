# GPT 노트북 marimo 변환 검증

- 작업일: 2026-11-09 (Asia/Seoul)
- 산출물: `outputs/gpt/20261109-203900-marimo/`
- 대상: `gpt/Chapter*.ipynb` 9개와 같은 이름의 `.py` 앱 9개

## 변경 내용

원본 Jupyter 파일을 보존하고 marimo 0.25.2 변환기로 설명과 코드를 변환했다.
Jupyter 설치 셀은 제거하고 `gpt/pyproject.toml`과 `uv.lock`에 marimo와 gensim을 추가했다.
셀 내부 `__name__` 조건 대신 실습 함수를 직접 호출하며, 셀 간 재정의는 변환기가 처리했다.
사전 학습의 학습·평가·생성 함수는 서로 참조하므로 같은 셀로 묶어 순환 의존성을 해소했다.
`nvidia-smi`는 명령이 존재하는 환경에서만 실행한다.

`marimo_runtime.prepare_run`은 실행별 `outputs/gpt/<시각>-<실습명>-<고유 ID>/`를 생성한다.
데이터·CSV·그래프·학습 체크포인트·생성 결과를 이 경로에 저장한다.
다운로드 GPT-2 가중치는 기존 `gpt/models/gpt2/` 캐시를 사용한다.
라이브러리 자체 캐시는 각 라이브러리 기본 경로를 유지한다.
공유 `previous_chapters.py`의 그래프 함수 두 개에는 선택적 `output_dir` 인자를 추가하고
원본 노트북 호출의 기본 경로 `outputs`는 유지했다. 저작권 안내도 유지했다.

## 실행 및 판정

별도 언급이 없는 명령의 작업 디렉토리는 저장소 루트다.
아래 `notebooks/.venv`는 기존 검증 환경이며, GPT 잠금 환경을 설치한 결과와 구분한다.

검증 환경: Python 3.12.15, marimo 0.25.2, torch 2.15.0+cpu,
matplotlib 3.11.2, numpy 2.5.4.
이 환경에는 tiktoken과 gensim이 설치되어 있지 않으며,
프로젝트 잠금 파일의 torch 제약은 기존 `>=2.8,<2.9`를 유지했다.
패키지 버전과 원본·변환본 SHA-256은 `environment-and-sources.json`에 기록했다.
초기 검사에서 발견한 순환 의존성은 수정했고 최종 `check-final.log`는 진단 없이 비어 있다.
샌드박스 내 marimo CLI 비동기 파일 검색이 멈춰 정적 검사는 샌드박스 밖에서 실행했다.

## 기록과 검증 한계

변환 로그, 변환 입력 사본, `check-initial.log`, `check-final.log`,
`attention-smoke.log`, `plot-path-smoke.log`, `plot-path-smoke/*.pdf`,
`environment-and-sources.json`은 위 산출물 경로에 있다.

모델·데이터 다운로드, Gensim 벡터 실습, GPT 잠금 환경 전체 설치,
1·2·4~7장의 전체 셀 실행과 GPU 학습은 수행하지 않았다.
모델·데이터 리비전은 원본 코드의 URL과 파일명을 유지했으며
해당 외부 리소스를 이번 검증에서 내려받거나 리비전 고정하지 않았다.
실제 학습 성공, 수렴, GPU 호환성 및 브라우저 UI의 전체 수동 검증을 의미하지 않는다.
