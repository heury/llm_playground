## 수정

교육용 ToyPolicy/ToyTokenizer와 고정 확률 설명을 제거하고 지정한 실제 가중치와 토크나이저를 사용한다.
노트북은 17개 셀, 코드 8개로 유지한다. 실제 토큰 조각, 응답, logp와 확률을 표시한다.
EOS 마스크는 고정 ID 예제와 실제 생성 응답 양쪽에서 확인한다.
첫 응답 하나로 역전파를 확인하며 optimizer 갱신은 하지 않는다.
원본 노트북에는 실행 출력과 실행 번호를 남기지 않았다.

## 검증 결과

- 코드 셀 8개 실행 및 모든 assertion 통과.
- 실제 입력 크기 [2, 21], G=2, 최대 생성 길이 16.
- 응답 크기 [4, 16]; 응답별 학습 토큰 수 [16, 16, 16, 16].
- 입력 복제 순서, 응답 분리, prompt_lens=P, 왼쪽 패딩 확인.
- 전체 logits에서 수동 계산한 토큰 logp가 엔진 반환값과 일치 (atol/rtol=1e-5).
- 첫 EOS 포함·그 뒤 제외·EOS 없는 행 포함 확인.
- rollout logp의 gradient 차단 및 재계산 후 유한하고 0이 아닌 lm_head gradient 확인.
- 예제 loss: 0.802107.
- 추가 G=1, 최대 생성 길이=8 실행 통과 (응답 크기 [2, 8]).
- 문서 상대 링크 및 고유 셀 ID 확인.
