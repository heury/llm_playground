# Attention 계산 흐름 보강과 3장 실행 검증

실행 ID: `20261109-181732-attention-flow`. [계산 흐름 검토](20261109-181232-attention-flow-review.md)의 내용을 반영했다. 대상은 [3장 노트북](../../notebooks/Chapter_3_Exercise_MiniMind_Attention.ipynb)이며 원본 MiniMind 모델은 수정하지 않았다.

## 변경 결과

- 전체 계산 지도와 Q/K/values의 역할을 사용 전에 제시했다. 어휘 크기 V_vocab과 value V의 기호를 구분했다.
- token 3개, head_dim=2의 고정 Q/K/values를 주고 token 하나의 내적→scaling→mask→확률→가중합을 직접 계산한다.
- score의 행 i/query 위치와 열 j/key 위치, softmax의 마지막 축을 설명했다. 현재 위치를 허용하고 미래 위치만 가리는 이유를 next-token 예측과 연결했다.
- √d scaling의 직관, 확률 행렬과 문맥 벡터의 차이, concat과 o_proj의 차이를 설명했다.
- 원래 한 줄이던 출력 계산을 context_per_head→context_by_token→concatenated→manual(output)로 분리했다. 각 shape와 token 하나의 weighted value·합·출력 일부를 출력한다.
- GQA의 Q head→KV head 공유와 K/V projection 파라미터 수를 실제 config에서 출력한다. 기본 공유는 [0,0,1,1]이다.
- 미래 변경 설명의 “앞 네 위치”를 길이에 독립적인 표현으로 바꾸고, mask OFF 실험에서 수동 경로와 복제한 원본 모듈 모두 mask를 끄도록 했다. 원본 attn은 causal 상태로 유지한다.
- 손실 하락이라는 공통 문구를 지우고 이 장의 판단 기준을 확률·가중합·shape·원본 일치·미래 차단으로 명확히 했다. 원본 소스 대응 문제와 접이식 해설을 넣었다.

핵심 수동 계산을 여러 셀로 나누었으므로 과제 회귀 스크립트는 source 첫 줄 대신 `attention-regression` 태그가 있는 실제 5개 셀을 선택하도록 바꿨다. 전체 실행 스크립트에는 `--end`를 추가해 3장만 검증할 수 있게 했다.
