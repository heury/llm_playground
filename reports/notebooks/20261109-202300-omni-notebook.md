## 수업 구성과 검증

30개 셀(설명 12, 코드/UI 18)로 9행 입력, 텍스트/음향 special ID의 공간 구분, projector와 placeholder 교체, bridge와 Thinker–Talker 합산, 공유/개별 embedding·head, 8개 코드북 지연 정렬, shift 및 CE·STOP 가중치, 역전파, projector 단독 학습, KV cache, 실제 짧은 스트리밍 호출, 화자 벡터 삽입, VAD 상태 전이를 다룬다. 예상·관찰 질문과 수정 과제·해설을 포함한다.

외부 인코더 로딩만 생략한 MiniMindOmni 하위 클래스를 사용한다. 특징 삽입과 end-to-end 경로에는 합성 특징을 반환하는 명시적인 가짜 인코더를 연결하며 원본 forward를 사용한다. 작은 독립 head/embedding 수식 검사 외에는 원본 adapter rank=256을 유지한다. 원본 Talker의 attention 설정이 Thinker의 축소 head 설정을 그대로 물려받지 않는다는 점도 표에 표시했다.

실행 결과:

- `[B,T]` 입력과 PAD 음향을 붙인 `[B,9,T]` 입력의 두 logits 일치.
- 음성·이미지 특징의 정확한 자리 교체 및 나머지 텍스트 embedding 유지.
- 원본 인코딩 경로가 수동으로 projector·교체한 입력과 일치.
- Thinker 전달 배율 기본값 3과 변경값 0에서 전체 셀 실행 통과. 배율 변경은 텍스트 logits를 유지하고 음향 logits를 변경한다.
- TalkerEmbedding/TalkerHead 수동 수식이 실제 출력과 일치.
- 지연 배치에서 코드북 k의 첫 정답 위치와 스트리밍 역지연 인덱스 확인.
- 동일 합성 배치의 공동 학습 5 step: 텍스트 CE 4.2250 → 3.6127, 음향 CE 30.6106 → 22.2892.
- 음향 CE만의 gradient norm: bridge 블록 1.5864, bridge 이후 블록 0, Talker 27.7568.
- projector만 학습 가능하게 했을 때 audio projector gradient norm 2.3528. 음성 인코더와 Thinker parameter gradient 없음.
- cache 사용/미사용의 마지막 logits 최대 오차: 텍스트 3.73e-8, 음향 3.58e-7. 허용오차 내 일치.
- 원본 stream_generate 10 step 실행 및 반환 구조 확인. 첫 8 step에는 audio_frame 없음.
- 화자 자리의 codec_proj 입력이 spk_proj 출력과 일치하고 텍스트 logits 유지.
- 가짜 VAD 확률로 speech_end와 interrupt 상태 전이 확인.

## 실행 명령과 환경

별도 표기가 없으면 작업 디렉토리는 저장소 루트다. 로그와 HTML은 위 산출물 폴더에 저장했다.

```bash
# 의존성 추가는 notebooks/에서 실행
uv add 'soundfile>=0.13,<1' 'librosa>=0.11,<1' 'onnxruntime>=1.23,<2'

# 전체 실행: exit 0 (run.log)
XDG_CONFIG_HOME=/tmp/omni-marimo-config MPLCONFIGDIR=/tmp/omni-matplotlib \
  notebooks/.venv/bin/python notebooks/minimind_omni.py

# 정적 검사: exit 0, 진단 없음 (check.log)
XDG_CONFIG_HOME=/tmp/omni-marimo-config MPLCONFIGDIR=/tmp/omni-matplotlib \
  notebooks/.venv/bin/marimo check notebooks/minimind_omni.py

# 전체 셀 재실행 및 HTML: exit 0 (export.log)
XDG_CONFIG_HOME=/tmp/omni-marimo-config MPLCONFIGDIR=/tmp/omni-matplotlib \
  notebooks/.venv/bin/marimo export html notebooks/minimind_omni.py \
  -o outputs/notebooks/20261109-202300-omni-validation/minimind_omni.html
```

UI 변경 검사는 노트북을 import한 뒤 `app.run(defs={'bridge_scale': SimpleNamespace(value=0.0)})`로 실행했다. [ui-regression.json](../../outputs/notebooks/20261109-202300-omni-validation/ui-regression.json)에 통과 여부와 해당 실행 수치 폴더를 기록했다. 브라우저에서 UI를 직접 클릭하는 검사는 수행하지 않았다.

환경: Python 3.12.15, Linux x86_64, torch 2.15.0+cpu, transformers 4.57.6, marimo 0.25.2, numpy 2.5.4, soundfile 0.14.0, librosa 0.11.0, onnxruntime 1.31.1. CPU float32, Thinker hidden=32·2층, Talker hidden=32·1층. seed는 모델 42, 독립 수식 예제 7, 생성 123이다. 초기 가중치와 입력은 로컬 합성으로 외부 모델·데이터 리비전은 없다.

[environment.json](../../outputs/notebooks/20261109-202300-omni-validation/environment.json)에 git HEAD, 원본·노트북·잠금 파일 SHA-256과 패키지 버전을 기록했다. 기본 실행 수치 원본은 `outputs/notebooks/20261109-202230-86b3fb-omni/metrics.json`, HTML 실행 수치는 `outputs/notebooks/20261109-202246-f7b3ca-omni/metrics.json`이다. 노트북 재실행 시 고유 실행 폴더를 추가한다.

## 실패·미실행과 한계

최초 제한 환경의 marimo check는 asyncio 파일 탐색 대기에서 멈췄다. 15초 진단 traceback을 `check-diagnostic.log`에 남기고 일반 실행 권한에서 같은 정적 검사를 통과했다. 멈춘 두 검사 프로세스는 종료했다. 최초 쉘의 `python` 명령이 없어 노트북 전용 `.venv/bin/python`으로 수정·실행했다. 실행 로그의 ONNX telemetry 디바이스 ID 저장 경고는 원본 모듈 import 때 발생했으며 실제 ONNX 세션이나 VAD 모델은 로드하지 않았다.

실제 SenseVoice·SigLIP·Mimi·화자 인코더, pretrained Omni 가중치, 실제 Parquet와 OmniDataset 전체, trainer 전체, CUDA·AMP·DDP, 실시간 마이크, 실제 음성 합성·복제·인식, open_thinking 경로와 여러 이미지/혼합 배치 전 분기는 검증하지 않았다. 합성 손실 감소는 범용 언어 성능·음질·일반화의 근거가 아니다. 수정 과제의 모든 설정 조합과 실제 수강생 이해도도 평가하지 않았다. 기본 config와 배율 0 변경을 검증했다.
