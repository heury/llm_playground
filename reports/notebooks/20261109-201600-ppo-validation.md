## 실행 제약과 검증 한계

최초 marimo check는 샌드박스의 asyncio/소켓 제한에서 멈췄고 HTML export도 로컬 커널 소켓 생성 PermissionError로 실패했다. 소켓 사용이 가능한 실행에서 동일 check/export를 다시 실행하여 모두 통과했다. HTML 종료 시 marimo multiprocessing resource_tracker가 semaphore 1개 정리 경고를 출력했다. 셀 실행 오류는 없었고 HTML과 지표 생성이 완료되었다.

실제 원본 trainer, 외부 Reward Model, GPU AMP/DDP, MoE, SGLang, scheduler, 누적 업데이트, 클라우드 학습은 실행하지 않았다. 샘플링은 전체 어휘 temperature=1로 통일하여 old/new 확률 정의를 맞췄고, 원본 temperature=.8 호출과 차이를 설명했다. EOS가 없는 길이 제한 종료는 원본처럼 bootstrap=0으로 취급한다. 합성 인사 과제의 학습 프롬프트 성능이며 별도 검증 분할·범용 한국어 성능·보상 모델 품질의 증거가 아니다. UI의 모든 조합을 전수 실행하지는 않았다.
