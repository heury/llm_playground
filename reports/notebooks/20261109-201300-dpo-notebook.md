# MiniMind DPO 노트북 검증

대상은 `notebooks/minimind_dpo.py`와 실행 안내 `notebooks/README.md`다.
원본 DPODataset, logits_to_log_probs, dpo_loss를 직접 import하며 원본 소스는 수정하지 않았다.
선호 쌍·채팅 템플릿·마스크·정답 이동·절단, 로그 확률 합산, Δ/β/gradient,
SFT 기준 모델 준비, DPO 학습·검증·생성, 과제와 해설을 포함한다.

## 환경·입력

작업 디렉토리: `/home/mind4u/dev/llm_playground/notebooks`.
기존 `.venv` 사용. Python 3.12.15, torch 2.15.0+cpu, transformers 4.57.6,
datasets 5.0.1, tokenizers 0.22.2, marimo 0.25.2, matplotlib 3.11.2.
외부 모델/데이터 리비전은 없고 현재 로컬 MiniMind 소스를 사용했다.
합성 6쌍 학습·2쌍 검증, seed 42, hidden=32, 2층 Dense, Q/KV head=4/2,
CPU float32, max_length=24. SFT 100 step 후 DPO 40 step, lr=0.001, β=0.5.

## 실행 명령

```bash
XDG_CONFIG_HOME=/tmp/minimind-marimo-config .venv/bin/python minimind_dpo.py
XDG_CONFIG_HOME=/tmp/minimind-marimo-config .venv/bin/marimo check --strict minimind_dpo.py
XDG_CONFIG_HOME=/tmp/minimind-marimo-config MPLCONFIGDIR=/tmp/minimind-matplotlib .venv/bin/marimo export html minimind_dpo.py -o ../outputs/notebooks/20261109-201300-dpo-validation/minimind_dpo.html
```

스크립트 실행 성공. 원본 함수의 수치 계산, 유효 응답 마스크, PAD/UNK 제외,
초기 log(2), 참조 gradient 없음·가중치 불변, 정책 갱신과 학습 손실 감소 assertion을 통과했다.
정적 검사에서 발견한 Markdown 표기 경고는 raw 문자열로 수정했다.
샌드박스에서는 정적 검사가 비동기 대기하고 HTML 내보내기는 로컬 소켓 PermissionError가 발생했다.
권한 확장으로 정적 검사와 HTML 내보내기를 실행했다. 진단 로그는 outputs에 보관한다.

## 결과

- 첫 DPO loss: 0.693147.
- 학습 loss: 0.693147 → 0.00041561.
- 검증 loss: 0.693147 → 0.00074077.
- 학습 6/6, 검증 2/2에서 참조 대비 Δ > 0.
- 참조 가중치 불변, 참조 gradient 없음, 정책 가중치 변경 확인.
- 검증 greedy는 전후 동일: `네 야옹 입니다 .`, `네 멍멍 입니다 .`.
  점수 개선과 생성 문장 변화가 별개임을 노트북에서 설명한다.
