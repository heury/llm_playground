## 환경과 실행

작업 디렉토리: `/home/mind4u/dev/llm_playground/notebooks`.
Python 3.12.15; 패키지: torch 2.15.0+cpu, marimo 0.25.2, transformers 4.57.6, datasets 5.0.1, tokenizers 0.22.2, matplotlib 3.11.2.

실행 명령:


누적 수 3 분기는 `app.run(defs={'sft_epochs': SimpleNamespace(value=20), 'sft_accumulation': SimpleNamespace(value=3)})`로 별도 실행했다.

## 판정과 결과

- marimo check: 종료 코드 0, 진단 없음.
- 전체 스크립트 실행: 종료 코드 0. 여러 턴 응답·EOS 정답, PAD 제외, 직접 CE와 원본 loss 일치, 가중치 복원 logits 완전 일치 assertion 통과.
- HTML 전체 셀 실행·내보내기: 종료 코드 0, `outputs/notebooks/20261109-201200-sft-validation/minimind_sft.html` 생성.
- 기본 SFT 60 epoch·누적 2: 학습 CE 5.602685 → 0.000921, 검증 CE 5.716255 → 0.938667.
- 정답 응답과 EOS 종료 동시 일치: 학습 1/8 → 8/8, 검증 0/4 → 2/4. 손실 감소와 일반화가 같은 의미가 아님을 관찰할 수 있다.
- 누적 3·20 epoch: 전체 셀 통과. 불완전한 마지막 누적 그룹 포함. 학습 CE 0.002740, 검증 CE 0.704799, 생성 학습 8/8·검증 3/4. 기본 실행과 epoch·누적 수 모두 다르므로 한 변수의 인과 비교로 해석하지 않는다.
- 정상 입력과 별개로, 응답 전 절단 시 정답 0개와 종료 없는 발화 뒤 PAD가 정답으로 남는 원본 동작을 재현한다. 잘못된 입력은 학습에 쓰지 않는다.

## 실패 이력과 검증 한계

초기 경계 관찰 코드가 원본 max_length와 다른 길이의 배열을 직접 넘겨 IndexError가 발생했다. 관찰용 Dataset 복사본의 max_length를 배열 길이에 맞추어 수정한 후 위 실행을 통과했다.
제한 환경에서 HTML의 로컬 소켓 생성이 거부되고 marimo check가 대기하여, 로컬 통신을 허용한 재실행으로 완료했다. export 종료 시 semaphore 정리 경고 1건이 있었으나 실행·HTML 생성은 성공했다.

실제 대규모 사전 학습·SFT, GPU AMP·DDP·wandb·원본 trainer 전체 실행, optimizer 중간 재개는 미실행이다. 저장은 교육용 float32 state_dict로 원본 half 배포 파일과 다르다.
작은 공백 사전과 동일 동물·소리의 새 질문 조합을 다루며, 자유 대화·미지 단어·범용 한국어 성능을 측정하지 않는다. 브라우저에서 직접 UI를 조작하는 수동 시각 검사는 하지 않았다.
