## 변경 내용

| 절 | 변경 |
| --- | --- |
| 도입 | 절별 원본 소스 대응표 추가 (10절에서 이동) |

## 판정 근거 (summary.json)

- 질문 위치 A/B logits 최대 차이: 0.0669 (> 0), BOS 위치 logits는 같음
- 이미지 위치 gradient L2 norm: [0.0509, 0.0412, 0.0636, 0.0552] (모두 > 0)
- 한 step 뒤 변경된 텐서: `vision_proj.*` 6개뿐
- marker 8개 연속: 길이 [10, 6]
- KV cache 사용 시 비전 인코더 호출 1회, 전체 재계산과 logits 일치
- VLMDataset 손실 대상 토큰 34개. 구간: user 헤더(제외) / image_pad×4(제외) / 질문+assistant 헤더(제외) / think+응답+`<|im_end|>\n`(대상)
