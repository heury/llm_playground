## 실행 환경과 명령

작업 디렉토리는 저장소 루트 `/home/mind4u/dev/llm_playground`.
Python 3.12.15, torch 2.15.0+cpu, transformers 4.57.6, marimo 0.25.2,
Pillow 13.0.0, datasets 5.0.1, pyarrow 26.0.1. CPU 스레드 2개.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 notebooks/.venv/bin/python notebooks/minimind_vlm.py
notebooks/.venv/bin/marimo check --strict notebooks/minimind_vlm.py
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 notebooks/.venv/bin/marimo export html notebooks/minimind_vlm.py \
  -o outputs/notebooks/20261109-201700-vlm-validation/minimind_vlm.html
uv --cache-dir /tmp/codex-vlm-uv lock --check --offline --project notebooks
```

검증에서는 `XDG_CONFIG_HOME=/tmp/codex-vlm-config`, `MPLCONFIGDIR=/tmp/codex-vlm-mpl`,
`UV_OFFLINE=1`, `UV_CACHE_DIR=/tmp/codex-vlm-uv`를 사용했다.
스크립트 전체 실행, 최종 HTML 내보내기, strict 검사, lock 검사 모두 종료 코드 0.
샌드박스에서는 HTML 로컬 커널 소켓 생성이 PermissionError로 실패하고 정적 검사가 대기하여,
같은 명령을 제한 밖에서 실행해 통과했다. 자동 승인 거부는 없었다.
HTML 내보내기 종료 시 Python resource_tracker의 semaphore 정리 경고 1건이 있었으며 종료 코드는 0이었다.
브라우저를 통한 수동 화면 검사는 수행하지 않았다.

## 검증 한계

구조와 연산 경로를 검증했다. 학습된 SigLIP/LLM의 의미 이해, 공개 VLM 체크포인트의 생성 품질,

텍스트로 구분해야 하는 구현 조건을 노트북에 명시했다.
