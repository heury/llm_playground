## 판정

- 정적 검사: 오류 False, 이슈 0.
- 전체 17개 셀 실행 완료, 예외 없이 종료 코드 0.
- 실제 `VLMDataset`과 collate로 `[B,T]=[2,40]`, 이미지 `[B,N,C,H,W]=[2,1,3,32,32]` 검증.
- 이미지 marker ID·4패치 수 일치, 응답·EOS만 유효 정답, PAD·marker 제외 확인.
- 원본 특징 교체 메서드에서 이미지 자리 교체와 텍스트 자리 보존 확인.
- 모델 CE와 직접 계산한 shifted CE 일치, Projector gradient 존재·고정 인코더/LLM gradient 없음 확인.
- 원본 initializer의 정책 0/1/2 학습 범위 확인. SFT는 가운데 1번 층을 고정하고 0·2번 층과 Projector 학습.
- 정렬→SFT 인수인계 가중치 일치, 고정 매개변수 변화 0, Projector 변화 확인.
- 저장 후 동일 로컬 인코더를 붙여 logits 완전 일치 확인. 저장 파일에는 vision_encoder가 없으며 optimizer 재개 검증과 구분.

기본 설정은 정렬/SFT 각 80 optimizer step, microbatch 4 × 누적 2, CPU float32, grad clip 1이다. 정렬 초기 학습률 0.02, SFT 0.003으로 원본 `get_lr` 스케줄을 적용했다. 모든 누적 그룹은 완전하며 단계별 응답 길이가 같다.

| 측정 | 결과 |
| --- | --- |
| 정렬 학습 응답 CE | 2.825046 → 2.594597 |
| SFT 검증 CE: 초기 | 2.881917 |
| SFT 검증 CE: 정렬 뒤 | 2.842649 |
| SFT 검증 CE: SFT 뒤 | 2.125232 |
| 초기: 응답+EOS 정확 일치 / EOS 종료 | 0/4 / 0/4 |

SFT 뒤 이미지 교환 CE 차이(반대 이미지−정상 이미지)는 0.198831, 0.203781, 0.192748, 0.206656로 네 표본 모두 양수였다. 이는 이 합성 표본에서 정상 이미지가 정답 예측에 유리했다는 관측이며 범용 이미지 이해 정확도의 증거로 확대하지 않는다. 생성 응답과 teacher-forced CE도 구분한다.

## 실패 이력·미실행·한계

- 최초 실행의 EOS 없는 label 데모에서 `generate_labels`에 max_length보다 짧은 배열을 넘겨 IndexError가 발생했다. 실제 Dataset처럼 max_length까지 PAD를 채우도록 노트북 데모를 수정했고 최종 전체 실행은 통과했다. 원본 소스는 수정하지 않았다.
- 일반 `marimo check`는 이 샌드박스의 event loop wakeup 제한으로 대기했다. 최종 검사는 위 timer를 사용하는 동일 marimo 검사 API로 0개 이슈를 확인했다.
- HTML export는 marimo 커널의 로컬 AF_INET listener 생성 시 샌드박스 PermissionError로 완료하지 못했다. `export.log`에 기록했으며 HTML이나 브라우저 UI 검증을 통과로 보고하지 않는다. 생성된 PNG와 실제 셀 실행 결과는 보관했다.
- 학습률·step UI는 기본값 실행을 검증했으며 모든 조합은 검증하지 않았다.
- 사전 학습 인코더/LLM, 대규모 데이터, 새 사물·새 질문 일반화, AMP·DDP·MoE·원본 train_epoch 전체·중간 체크포인트 재개·GPU 메모리는 미실행이다.
- 배포 가중치는 원본의 encoder 제외 정책을 따르되 실습에서는 float32를 유지한다. 원본의 half 저장 오차를 검증한 것은 아니다.
